1. Comment fonctionne un site web ?

HTML — le contenu

Il donne une structure à la page : titres, textes, images et boutons.

<h1>Bonjour !</h1>

CSS — l'apparence

Il gère les couleurs, les tailles, les espaces et la disposition.

h1 { color: blue; }

JavaScript — les actions

Il permet de réagir aux clics, vérifier un formulaire ou modifier la page.

alert("Salut !");
À retenir : une balise HTML s'écrit souvent avec une ouverture <p> et une fermeture </p>. Le contenu se place entre les deux. Certaines balises, comme <img>, n'ont pas de balise de fermeture.

2. Les lignes de base d'un fichier HTML

Un fichier de page web se termine généralement par .html. Voici une structure complète minimale :

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Mon premier site</title>
</head>
<body>
  <h1>Bonjour !</h1>
  <p>Voici mon premier site.</p>
</body>
</html>

<!DOCTYPE html>

Indique au navigateur qu'il doit interpréter la page comme du HTML moderne.

<html lang="fr">

Contient toute la page. lang="fr" indique que la langue principale est le français.

<head>

Contient les informations de la page, comme son titre, son encodage et les fichiers CSS. Ces informations ne sont généralement pas affichées dans la page.

<meta charset="UTF-8">

Permet d'afficher correctement les caractères, notamment les accents.

<meta name="viewport" ...>

Aide la page à s'adapter à la largeur d'un téléphone ou d'un ordinateur.

<title>

Définit le titre affiché dans l'onglet du navigateur.

<body>

Contient l'essentiel du contenu visible du site.

3. Écrire et organiser du texte

<h1> à <h6>

Créent des titres de différents niveaux. h1 est le titre principal ; h2 un sous-titre, etc.

<h1>Mon site</h1>
<h2>Présentation</h2>
<h3>Mes passions</h3>

<p>

Crée un paragraphe.

<p>J'apprends à coder.</p>

<br>

Fait passer le texte à la ligne. À utiliser pour un vrai retour à la ligne, pas pour créer de grands espaces.

Bonjour<br>tout le monde !

<strong>

Indique que le texte est important. Il apparaît généralement en gras.

<strong>Attention !</strong>

<em>

Met un accent sur un mot ; il apparaît généralement en italique.

C'est <em>important</em>.

<mark>

Surligne un passage pour le faire ressortir.

<small>

Affiche une note ou un texte secondaire plus petit.

<hr>

Marque une séparation thématique, souvent représentée par une ligne horizontale.

<!-- commentaire -->

Ajoute une note dans le code qui n'est pas affichée sur la page. Attention : elle reste visible dans le code source.

4. Ajouter des liens et des images

<a href="...">

Crée un lien vers un site ou une autre page.

<a href="https://example.com">
  Visiter le site
</a>

Pour ouvrir le lien dans un nouvel onglet, on peut ajouter target="_blank" rel="noopener noreferrer".

<img>

Affiche une image. src indique son adresse et alt décrit l'image si elle ne se charge pas ou pour les lecteurs d'écran.

<img src="photo.jpg"
     alt="Un paysage">

<figure> et <figcaption>

Permettent de regrouper une image et sa légende.

<figure>
  <img src="photo.jpg" alt="Un chat">
  <figcaption>Mon chat</figcaption>
</figure>

<audio>

Ajoute un lecteur audio. L'attribut controls affiche les boutons du lecteur.

<audio controls src="son.mp3"></audio>

<video>

Ajoute une vidéo à la page.

<video controls width="400">
  <source src="video.mp4" type="video/mp4">
  Votre navigateur ne peut pas lire cette vidéo.
</video>

5. Faire des listes et des tableaux

<ul> et <li>

Créent une liste à puces. Chaque élément se place dans <li>.

<ul>
  <li>HTML</li>
  <li>CSS</li>
  <li>JavaScript</li>
</ul>

<ol>

Crée une liste numérotée, par exemple des étapes à suivre.

<ol>
  <li>Ouvrir l'éditeur</li>
  <li>Écrire le code</li>
  <li>Tester la page</li>
</ol>

<table>, <tr>, <th>, <td>

Construisent un tableau : table est le tableau, tr une ligne, th une cellule d'en-tête et td une cellule normale.

<table>
  <tr><th>Langage</th><th>Rôle</th></tr>
  <tr><td>HTML</td><td>Structure</td></tr>
</table>

6. Créer un formulaire

Les formulaires servent à demander des informations. Pour enregistrer ou envoyer réellement les réponses, il faut aussi prévoir un traitement adapté.

<form>

Regroupe les champs d'un formulaire.

<label>

Donne un nom à un champ. Son attribut for doit correspondre à l'id du champ.

<input>

Crée un champ. Le type peut être text, email, password, number, checkbox ou radio.

<textarea>

Permet de saisir un texte sur plusieurs lignes.

<select> et <option>

Créent une liste déroulante de choix.

<button>

Crée un bouton. Dans un formulaire, type="submit" sert à envoyer et type="button" crée un bouton d'action ordinaire.

<form>
  <label for="prenom">Ton prénom :</label>
  <input id="prenom" name="prenom" type="text" required>
  <button type="submit">Envoyer</button>
</form>

7. Les balises qui organisent une page

<header>

Contient souvent le titre, le logo ou l'introduction d'une page ou d'une section.

<nav>

Regroupe les principaux liens de navigation.

<main>

Contient le contenu principal de la page.

<section>

Regroupe une partie du contenu autour d'un même sujet, souvent avec un titre.

<article>

Contient un contenu qui peut se comprendre seul, comme un article ou une publication.

<aside>

Contient une information complémentaire, comme un encadré.

<footer>

Contient souvent les informations de bas de page.

<div>

Regroupe des éléments sans leur donner de sens particulier. Pratique pour organiser la mise en page avec CSS.

<span>

Regroupe une petite partie de texte ou un élément en ligne, souvent pour lui appliquer un style.

<code> et <pre>

code désigne du code informatique. pre conserve les espaces et les retours à la ligne.

8. Les attributs à connaître

id

Donne un identifiant à un élément. Il doit être unique dans la page.

<h2 id="presentation">

class

Associe un élément à une classe CSS. Plusieurs éléments peuvent avoir la même classe.

<p class="important">

href

Indique la destination d'un lien <a>.

src

Indique la source d'un fichier, par exemple une image ou une vidéo.

alt

Décrit une image pour les personnes qui ne la voient pas et en cas de chargement impossible.

style

Permet d'ajouter du CSS directement à un élément. Pour un grand site, une feuille CSS est généralement plus pratique.

title

Fournit une information complémentaire, parfois affichée au survol.

required, placeholder, name

required rend un champ obligatoire ; placeholder affiche une indication ; name donne un nom à la donnée envoyée.

9. Les premières notions de CSS

Le CSS se place dans un fichier style.css relié au HTML avec <link rel="stylesheet" href="style.css">, ou dans une balise <style> dans le <head>.

body {
  font-family: Arial, sans-serif;
  background-color: #f2f5ff;
  color: #222;
}

h1 {
  color: purple;
  text-align: center;
}

.carte {
  background: white;
  padding: 20px;
  border-radius: 12px;
}

color

Change la couleur du texte.

background-color

Change la couleur de fond.

font-size

Définit la taille du texte, par exemple 18px.

margin

Ajoute de l'espace à l'extérieur d'un élément.

padding

Ajoute de l'espace entre le contenu et le bord de l'élément.

border et border-radius

Créent une bordure et arrondissent les coins.

display, flex, grid

Contrôlent la façon dont les éléments sont disposés.

width et height

Définissent la largeur et la hauteur d'un élément.

10. Les premières notions de JavaScript

JavaScript rend la page interactive. On peut écrire le code dans un fichier script.js, puis le relier avec <script src="script.js" defer></script>.

// Afficher un message dans la console
console.log("Bonjour !");

// Créer une variable
const prenom = "Hugo";

// Réagir à un clic sur un bouton
document.querySelector("#monBouton").addEventListener("click", () => {
  alert("Salut " + prenom + " !");
});

const et let

Créent des variables. Utilise souvent const si la variable ne doit pas être réassignée, et let si sa valeur doit changer.

function

Permet de regrouper des instructions pour les réutiliser.

if et else

Exécutent des instructions selon une condition.

addEventListener

Permet de lancer du code lorsqu'un événement se produit, comme un clic.

querySelector

Sélectionne le premier élément HTML qui correspond au sélecteur indiqué.

console.log()

Affiche une information dans la console du navigateur, utile pour comprendre son programme.

11. Exercice : crée ta première page

Essaie de comprendre ce code, puis copie-le dans un fichier nommé index.html et ouvre-le dans ton navigateur.

<!DOCTYPE html>
<html lang="fr">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>Ma page</title>
  <style>
    body { font-family: Arial; padding: 20px; }
    h1 { color: purple; }
    button { padding: 10px; cursor: pointer; }
  </style>
</head>
<body>
  <h1>Salut !</h1>
  <p>Je suis en train d'apprendre le HTML.</p>
  <button id="bouton">Clique ici</button>
  <p id="resultat"></p>

  <script>
    document.querySelector("#bouton").addEventListener("click", () => {
      document.querySelector("#resultat").textContent =
        "Bravo, ton premier bouton fonctionne !";
    });
  </script>
</body>
</html>
Défi : change le titre, ajoute une deuxième phrase, modifie la couleur du titre et crée un lien vers un site que tu aimes.

12. Quelques bonnes habitudes

  • Indente ton code pour voir quels éléments sont à l'intérieur des autres.
  • Ferme les balises qui doivent l'être.
  • Utilise des titres dans le bon ordre et des descriptions alt pour les images utiles.
  • Garde les fichiers du site ensemble et vérifie les noms et les extensions.
  • Teste souvent dans le navigateur et lis les messages d'erreur de la console.
  • Fais une copie de sauvegarde avant une grosse modification.

Tu n'as pas besoin de tout retenir par cœur : garde ce guide comme dictionnaire et entraîne-toi avec de petits projets. 🚀
